# Public evidence data

`data/evidence/` contains only redistributable aggregate or validation artifacts selected from the frozen publication evidence state.

The public package is intentionally not a security-level dataset. Licensed Norgate source data, the point-in-time ASX 200 market panel, historical constituent-level data, daily security-price histories, and other excluded security-level outputs are not published here.

The evidence package is designed to support manuscript table/figure reproduction and independent checking of the reported aggregate inferential conclusions.
